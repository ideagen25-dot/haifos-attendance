This is an essential question. Here is a clear explanation of how the database works, how attendance updates across different devices, and how to keep it 100% free ($0).

---

### The Problem: Local Storage vs. Cloud Database

- If you deploy a website that only uses your browser's localStorage, any attendance you post on your laptop only exists inside that laptop's browser.
- If a student opens the website from their smartphone, their phone won't have your laptop's browser memory.
- Therefore, for students to see updated attendance and verify certificates on any phone or computer worldwide, the system needs a shared cloud database.

---

### The Plan: Supabase Free Tier (100% Free Forever)

To keep costs strictly at $0, the project is integrated with Supabase (open-source cloud PostgreSQL):

- Database Storage: 500 MB free (we need ~2 MB for 100,000+ attendance logs & students) -> $0.00
- Monthly Active Users: 50,000 users (unlimited public verification requests) -> $0.00
- Server File Storage: 0 MB needed (certificates render dynamically on-the-fly) -> $0.00
- Credit Card: Not Required (Sign up with GitHub / Google) -> $0.00

---

### How the Data Flows

[ Admin Computer ]
      │
      ▼  (Admin marks daily attendance or generates certificate)
[ Supabase Cloud PostgreSQL Database ]  <─── 100% Free ($0)
      │
      ▼  (Live real-time query)
[ Student Smartphone / Any Device ]
   - Checks Attendance: sees live % and today's session
   - Verifies Certificate: dynamically renders certificate on-the-fly (0 server files)

1. Admin marks attendance on their computer -> Saved to the Supabase database.
2. Student opens your-site.netlify.app on their phone -> Fetches the live attendance records directly from Supabase.
3. Admin clicks "Approve Certificate" -> Certificate metadata (ID, grade, issue date) is saved to Supabase, and the automated email is sent to the student.
4. Student clicks the verification link -> The student's browser queries Supabase and dynamically draws the high-res certificate on their screen (no PDF files stored on the server).

---

### How to Connect It (Takes 2 Minutes)

All the code and SQL schemas are already built into your project. Here is how to activate it:

1. Create a Free Database:
   - Go to supabase.com and create a free project (e.g. haifos-portal).
2. Create the Tables (1 Click):
   - In Supabase, click SQL Editor on the left menu.
   - Open and copy the contents of supabase_schema.sql in your project folder.
   - Paste it into the SQL editor and click Run.
3. Connect to Your App:
   - In Supabase, go to Project Settings -> API and copy:
     - Project URL (e.g. https://xyzcompany.supabase.co)
     - anon / public key (e.g. eyJhbGciOi...)
   - Open your portal, go to Admin Portal -> Tab 4: "Settings & Deployment".
   - Paste the Project URL and Anon Key and click Save Settings.
   - Click "Test Cloud Connection" -> You will see LIVE CLOUD CONNECTED.
   - Click "Sync All Local Data to Supabase (1-Click)" to upload all initial courses and sample students.
